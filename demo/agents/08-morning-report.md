# Agent 8: Morning report

Schedule: every morning at 7 AM.
Connectors in a live setup: Supermetrics for Google, Meta and LinkedIn ads. In this demo, run `scripts/ad_report.py` on `data/ads/ads_daily.csv`.

## Instructions

Pull yesterday's ad numbers. Tell the operator what each ad spent and how many sign-ups it brought, plus the last 7 days. Take all numbers from the script output. Do not calculate them yourself.

List the ads with no sign-ups over the last 7 days as candidates to turn off. The operator decides. You cannot change a campaign.

Add what worked to the Wins and flops doc, so a good ad from Tuesday shapes next Monday's ideas. If a sample is small, say so.
